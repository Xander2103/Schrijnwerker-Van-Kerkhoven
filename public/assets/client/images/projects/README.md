Foto's van nieuwe projectpagina's horen hier, één map per projectsleutel:

    projects/{project-key}/hero.webp
    projects/{project-key}/01.webp
    projects/{project-key}/02.webp

Projecten die bestaande categoriefoto's hergebruiken verwijzen vanuit
config/projects.php rechtstreeks naar de bestaande map (images/ramen/, ...).
Die bestanden worden niet verplaatst: GalleryScanner leest die mappen uit voor
de categoriegalerijen.

Zie docs/projects.md.
